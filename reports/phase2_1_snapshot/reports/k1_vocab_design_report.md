# 韓国語 Graded Reader K1 語彙設計 Phase 1

作成日: 2026-10-09。状態: **人間レビュー前の初版**。

Core原案は300エントリ。固有名詞を除く予算対象は299エントリである。
原案を保存し、한국を固有名詞台帳へ移して아니다に置換したCore候補300語と、Expansion500語を作成した。
現行候補は合計800エントリ、E1/E2/E3は200/200/100。文法は29項目。
教材本文・アプリ・TTS・UI・K2語彙DBは作成していない。文法JSONには29個の短い文例だけを収録した。

**先に決めるべき点:** 500語を250本までに1本2語以下で本文初出させると、全250本で2語導入が必須になる。
また、2未知語の本文内導入と99%既知率は、通常の短い教材では同時に満たしにくい。
件数・SchemaのPASSと、教材生成へ進める判断は分ける。Fで具体的な判断事項を示す。

### 問題点と分類

原案の見出しはテーマ区分であり、厳密なPOS表ではない。JSONへの写像は以下のようにした。

| 語・原案の置き場所 | 共通POS・中心義 | 判断 |
|---|---|---|
| 있다（動詞欄） | adjective / exist | 存在・所有義。滞在の動詞義・文法内の補助用法は別に扱う |
| 없다（動詞欄） | adjective / not_exist | 非存在の形容詞。없는を個別異形として記録 |
| 필요하다（動詞欄） | adjective / necessary | N이/가 필요해요。動詞の目的語構文を流用しない |
| 어느 | determiner / which | 「どの」 |
| 왜 / 어떻게 / 같이 / 모두 | adverb | 모두は副詞義のみ。모두가の名詞用法は未登録 |
| 언제 | adverb / when | 언제 가요?を許可。언제가の代名詞義は未登録 |
| 지금 / 매일 / 일찍 | adverb | 副詞義に限定。지금은等の別POS用法を自動許可しない |
| 시 / 분 / 주 / 월 / 년 | counter | 韓国語の依存名詞・単位表現を共通POSに写像 |
| 그리고 / 하지만 / 그래서 / 그런데 | conjunction | 韓国語では接続副詞。共通DBでは接続機能を優先 |

필요하다の形容詞扱いは[国立国語院の回答](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=314690)を確認した。
언제の代名詞／副詞の区別は[韓国語基礎辞典](https://krdict.korean.go.kr/eng/dicMarinerSearch/search?ParaWordNo=&mainSearchWord=%EC%96%B8%EC%A0%9C&nation=eng&nationCode=6)に基づく。
辞典分類を共通POSへ写像する際、機能語は文法DB、依存名詞の数える機能はcounterへ集約する。

### 難度・意味境界

明らかに専門的・高度なCore語は見当たらない。ただし「初級単語」と「K1で全用法を許可できる単語」は同じではない。

- 사용하다 / 필요하다 / 출발하다 / 도착하다は初級生活場面に再利用できる。漢字語だから一律に排除しない。
- 파랑は色名の名詞であり、파란は파랑の活用ではない。파랗다はExpansion E2に別登録した。
- 뭐 / 무엇はほぼ同義の口語形・基本形。原案を尊重して両方保持し、生成では뭐を優先する。
- 아버지 / 어머니と엄마 / 아빠は人物関係・呼び方の差がある。機械的に言い換えない。
- 너は親しい相手向け。해요체の会話で初対面・目上へ一律に使用すると不自然。
- 쓰다はCoreでは「書く」のみ。「使う」「かぶる」を無料の追加義にしない。
- 눈はCoreでは「雪」のみ。目はE1。차は「お茶」のみで、車の略称には使用しない。
- 일は「仕事・作業」と数詞「一」だけ。日付の単位「日」、出来事の「事」を自動許可しない。
- 밥の炊いた米／日常の食事は密接な慣用的連続義として1エントリ。別義を無限に束ねる前例にはしない。
- 아침は朝、저녁は夕方・晩に限定し、朝食・夕食義は無料で追加しない。점심は昼食義を中心にした。

### 選定方針と確信度

家、買い物、食事、移動、学校、仕事、約束、困りごと、感情という具体場面への再利用を優先した。
反意語、他動／自動、移動の行く／来るは物語上の意味差があるため、単なる類語とは区別した。
ただし独立lemmaとして登録した複合動詞・使役・受動語から、生産的な派生文法を自由に作ることは認めない。
専門語・行政語・ニュース語は採用せず、抽象語は身近な具体場面で使えるものに狭めた。

`confidence`はhigh489、medium11、low0。highは設計者の初版判断であり、辞書全件照合済み・実測高頻度という意味ではない。
mediumは제일、조부모、관계、미술관、박물관、찍히다、함께、결국、관심、기차역、정보。
特にほぼ同義の함께・제일、専門場面へ寄りやすい展示施設、抽象語の再利用価値を人間が確認する。
500語を正式確定するための穴埋め扱いにはせず、必要なら入替・Tier再配置をする。全500語の頻度順位は今回測定していない。

rankはCore原順1〜300、E1 301〜500、E2 501〜700、E3 701〜800。
各Tier内は意味カテゴリと初版の優先順であり、コーパス順位ではない。

lemma+POS+senseでのCore重複は0。同表記を持つ7lemmaは以下の8追加エントリである。

| lemma | Core | Expansion |
|---|---|---|
| 개 | noun / dog | E1 counter / item_unit |
| 눈 | noun / snow | E1 noun / eye |
| 쓰다 | verb / write | E2 adjective / bitter |
| 이 | numeral / two_sino | E1 determiner / this、E2 noun / tooth |
| 저 | pronoun / i_humble | E1 determiner / that_over_there |
| 찍다 | verb / take_photo | E2 verb / stamp |

Expansion内部の同表記も、봉지（袋／袋数）、달（か月／月天体）、다리（脚／橋）、배（腹／梨）、풀（のり／草）、새（鳥／新しい）に限定した。
Core内部の일と合わせ、800エントリの異なるlemma表記は785。
語形の네は数詞넷の連体異形と応答네、내/제等は代名詞縮約のため、表面文字列だけではsenseを判定できない。

### 初出範囲・再遭遇

- E1: 001〜160の中で重要度別に候補範囲。指示詞・応答・基本助数詞などは001〜080へ前倒し。
- E2: 061〜250。主な候補範囲は061〜190、071〜210、081〜230、091〜250。
- E3: 151〜250。主な候補範囲は151〜220、161〜230、171〜240、181〜250。
- 251〜300は新規導入範囲に含めない。
- 全Expansion語のtarget_exposuresは6。初出1教材＋最低5つの別教材での再遭遇。同一教材内の反復はこの6へ重複加算しない。

導入範囲は「その教材で必ず出す」予約ではない。区間と2枠制約だけに対する配置可能性をvalidatorで確認した。
500語すべてを配置できるが、250本すべて2語導入となる。ジャンル、難度、既知率、実際の再遭遇は未証明。
6回ならExpansionだけで最低3000の「語×異なる教材」出現が必要。300本平均10語分だが、後半での密度を別途設計する必要がある。

| 먼저 / 일단 / 우선 | Core / E2 / K2送り | 順序は먼저。暫定の「まずは」のみ일단。言い換え用に増やさない |
| 자주 / 자꾸 | Core / E2 | 頻度と反復の含意に差がある。反復して困る等の場面で자꾸 |
| 좋다 / 좋아하다 | Core / Core | 状態・評価と対象への好みで構文が異なるため両方必要 |
| 예쁘다 / 귀엽다 | Core / E2 | 美しさと幼さ・愛らしさの差。人物・物を機械的に言い換えない |
| 재미있다 / 즐겁다 / 행복하다 / 기쁘다 | Core / E3 / E1 / E1 | 興味、活動の楽しさ、生活の幸福、出来事の喜びを区別。同一文脈で類語連打しない |
| 덥다 / 뜨겁다、춥다 / 차갑다 | Core / E1 | 天候・環境と物の温度で必須の意味差 |
| 밥 / 쌀 | Core / E1 | 炊いた米・食事と未調理の米で別物 |
| 생선 / 물고기 | E1 / E2 | 食材と生きた魚で区別。料理に물고기を機械的に使わない |
| 끝나다 / 끝내다、열다 / 열리다 | Core / E1、Core / E2 | 自動／他動の参与者が違うため必要 |
| 가다・돌아가다 / 오다・돌아오다 | Core / Core・E1 | 話者の位置と移動方向を示す。単なる類語ではない |
| 빌리다 / 빌려주다 / 돌려주다 | Core / E1 / E1 | 借りる、貸す、返すの出来事が違い、物語の因果に必要 |
| 방 / 침실、책상 / 식탁 | Core / E2 | 一般語と機能別の具体物。区別が不要ならCoreを使う |

類語を入れることは言い換えの義務を意味しない。生成時はCore > E1 > E2 > E3の範囲で、意味が足りる最優先語を反復する。
함께・제일・조부모・기차역の採用は特に再検討する。片方を外す場合も500件を黙って変えず、代替の必要性と差分をレビューする。

## E. 不自然さのリスク

### 語彙不足・語義の過剰拡張

方向・手段の(으)로、起終点の부터/까지、限定の만、比較の보다/와・과、長形否定-지 않다、理由等の名詞化-기は29項目にない。
単語を増やしてもこれらを自由に使えるわけではなく、初級の日常文にも言いにくい内容が残る。
衣服の動詞では帽子をかぶる쓰다義がなく、使う쓰다義もない。日付の일、数字の0（영/공）、30以上の固有十位数詞も未登録。
語義を無料で広げるより、必要場面を先に決めて入替・追加義の費用をレビューする。
上下・左右の方向や移動の手段を無理な文へ押し込まず、許可された単純な事態へ場面を設計する。

### ジャンル偏り

食事・家・学校・買い物・移動は作りやすい。ニュース、科学説明、仕事の専門場面は対象外。
人・社会関係40語には親族・学齢・職業が多く、全教材が家族と学校へ偏る可能性がある。
成人の日常生活、休日、物の貸し借り、忘れ物、天候、小さな失敗・解決も計画へ入れる。
美術館・博物館を採用しても、難しい文化説明を必要とする話にはしない。

### 単調さと不自然な言い換え

短文・反復は自動化のために意図した性質であり、語彙の多様化で解消しない。
変化させるのは人物の目的、時間、物の所在、失敗と解決、出来事の順序。
「同じ語を避ける」目的で함께/같이や가장/제일を交互に入れない。
主語を毎文저는等で補うと不自然になりやすいため、指示対象が明確な範囲で省略を許可する。
名詞만を並べる、自然な쓰다を全場面使用하다へ置換する等の不自然さは母語話者レビューで確認する。

### 形態・POS・語義の誤判定

formsは一部の異形の例示であり、網羅的な生成表・認識表ではない。가요/갔어요/가고/가면等は同じ가다へ正規化する。
活用可能=trueでも、未許可の連体形・語尾・意味を許可するわけではない。
있다/없다の連体形、ㅎ/ㅂ/ㄷ/르/으等の不規則、指示詞・数詞・身体語の同表記は形態素解析と文脈の両方を必要とする。
動詞の現在連体形と完了した状態を混同せず、화난等を無断で文法許可することを避ける。
辞書全義をglossへ詰めず、sense別に許可域を守る。今回のvalidatorはこの言語的正しさを自動判定しない。

### 定型表現の抜け道

文法外で認める固定句は안녕하세요、감사합니다、죄송합니다、안녕히 가세요、안녕히 계세요の5種類だけ。
最大2出現/教材、会話の挨拶等に限定し、完全一致で認可する。構成語の自由使用や합니다体全般を許可しない。
괜찮아요は通常語彙E1 괜찮다＋g02であり、未導入語を例外扱いで迂回できない。
800語予算外の固定句も読む負荷はある。未学習なら未知率へ含め、事前に理解できる状態へする。
固有名詞も予算から除くが、理解負荷から黙って除くことはしない。

## F. 次フェーズへの提案

### 1. 導入容量を決める

500 ÷ 2 = 250本。251〜300で新出語を避ける条件では、001〜250に0〜1語回を1本入れるだけで全500語の本文初出は収まらない。
現在のJSONは条件を変更せず、候補範囲として数学的に配置可能な案を提供している。

人間が選ぶ具体案は次のいずれか。

| 案 | 得られること | 必要な仕様判断 |
|---|---|---|
| 500語を全て本文初出、001〜250は毎回2語 | 現件数・最終50本の新出0を維持 | 前半に復習専用回を作れない。読み始める前の準備が必要 |
| 800語を許可語彙とし、500語全ての初出を必須にしない | 新出0〜1語回を作れる | 未使用Expansionには導入・再遭遇保証を付けない |
| K1教材数・導入期限・1本上限のいずれかを見直す | 復習回と全語導入を両立しやすい | 現仕様の変更が必要。今回は自動適用していない |

### 2. 99%の測定と読前既知化を決める

「既知」は、DB内に存在することではなく学習者が読む前に意味を処理できること。
延べ内容語数N、未知出現数Uで( N − U ) / N ≥ 0.99とする。新出語の再出現も、その読書中は自動的に既知へ変更しない。

- U=2ならN≥200が必要。新出2語を各3回反復するとU=6なのでN≥600が必要。
- 어절を分母にした場合、120〜180어절の本文で未知2어절なら98.33〜98.89%。99%には届かない。
- 本案の分母は内容語の意味単位なので어절数と一致しない。しかし「常に200以上ある」とは仮定できない。
- 推奨案は**初出2語を読前に提示し、理解を確認してから本文を読む**こと。提示しただけで既知とみなさない。
- 読前提示した2語も、その教材の新規導入数2へ含める。既知率の計算だけを操作して導入制約から除外しない。
- 事前提示を採用しないなら、語彙導入量または99%基準・本文長の仕様を人間が再検討する。

既知率の単位・助詞等の除外・固有名詞・固定句の扱いをprofileに明示したが、読前確認方式は未確定。
前提となるCore300についても、学習者がすべて知っていることを別途確認する。

### 3. 言語レビューを終える

- Core 한국→아니다置換を採用するか。原案保持版との差分を確認する。
- 800エントリの中心義・POS・日本語義と、文法で作れる自然な用例を韓国語母語話者が確認する。
- medium11語、Cの40境界語、Dの類語群を確認する。特に함께/제일/기차역は追加価値を再判断する。
- 指示連体詞・助数詞をCoreへ昇格するか、기억하다/어떻다/잠깐のTierを前倒しするかを判断する。
- 同表記語、依存名詞、数詞の異形、縮約形の正規化・sense判定方法を決める。
- 29文法に含めない形が不可欠な場面を洗い出し、場面変更か文法改訂かを判断する。例外で迂回しない。

### 4. 語彙スケジュールを先に作る

大量本文の前に「語→初出教材→最低5つの再遭遇教材」の台帳を作る。
同じsenseが実際に使われた教材だけを計数し、同一教材内の反復を6教材へ換算しない。
late E3も初出250なら251〜300に50本あるので、時間的には再遭遇余地がある。実際の意味・ジャンルの適合は未検証。
家・食事だけに偏らないジャンル配分と、各教材の既知語集合のスナップショットも定義する。
人間確認後の次Phaseは少数の試作を評価してから大量生成へ進む。今回は試作本文も生成していない。

## 検証・再現性

```powershell
python -m pip install -r requirements-dev.txt
python scripts/validate_k1_vocab.py
python scripts/validate_k1_vocab.py --json
python -m unittest discover -s tests -v
```

検証対象: Core/Expansion/合計、ID、rank、lemma+POS+sense、原案を含むCoreとの重複、Tier、カテゴリ、必須フィールド、POS、タグ、導入範囲、再遭遇数、NFC、JSON重複キー・非標準数値、文法・補助データSchema。
導入区間の大域的な配置可能性も確認する。SchemaはDraft 2020-12、外部ネットワークを必要としない。
構造検証はPASS、errors0。4つのテストメソッドで正常系と24件の破損ケースを確認した。
警告4件は導入余裕0・99%測定方針・言語品質未保証・Core置換候補に関する設計事項。
機械結果は`reports/k1_vocab_validation_result.json`へ保存する。本文の既知率や再遭遇実績を検証したものではない。

ファイル: `config/languages/ko/k1/`の語彙・文法・例外・profile・Schema・固有名詞台帳、`scripts/`の手選定シードとvalidator、`tests/`の破損検出テスト、`requirements-dev.txt`、`README.md`、本レポートと検証結果JSON。
多言語化ではlanguage/levelごとに同じ共通POS・lemma+POS+senseを使い、語形・文法・固有名詞・計数単位の言語差を各profileへ配置する。
