### 削除候補 → 代替候補 → 理由

7語とも現在はK1許可語彙500の中に保持する。推奨判断は「K2送り・一対一入替」であり、実際の削除・採用は行っていない。
`expansion_replacement_proposals.json`は語彙DBとは別の提案台帳で、`applied=false`、予算対象外。

| 削除・K2送り候補（現E3） | 問題 | 代替候補（未採用） | 中心義・理由 |
|---|---|---|---|
| 함께 | Core 같이とほぼ同義 | 가만히 / adverb / without_moving | 動かずに。待つ・座る等の具体動作を補う。音量の조용히とは区別 |
| 조부모 | 할머니/할아버지で足りる | 아저씨 / noun / adult_man_address | 成人男性への「おじさん」。近所・店・交通の具体人物を補う |
| 기차역 | Core 역との差が小さい | 시간표 / noun / timetable | 時間割・時刻表。学校・交通・仕事の具体的な一覧表 |
| 찍히다 | 受動の負荷・写真場面への偏り | 충전하다 / verb / charge_battery | 充電する。携帯電話・コンピューターの家・学校・仕事・旅行場面 |
| 관계 | 抽象的な人物関係 | 동갑 / noun / same_age | 同い年。年齢・友達・家族を具体的に記述できる |
| 정보 | 抽象的で具体語で置換しやすい | 충전기 / noun / charger | 充電器。持ち物・貸し借り・忘れ物・旅行に再利用できる |
| 가장 | 제일と最上級の重複 | 방금 / adverb / just_now | たった今。近い未来の곧、現在の지금と異なる直前過去を補う |

全候補は既存Core/Expansionとlemmaが重ならず、現在の7語と同じカテゴリ・Tierに仮置きした。
したがって一対一の入替だけなら、Core300・Expansion500・Total800、Tier200/200/100、カテゴリ配分を維持できる。
validatorはこの**仮適用時の件数と意味キー衝突**も検証する。仮適用はDBへの書込みではなく、候補の言語品質や6教材での使用を保証しない。
候補の早期Tier昇格は、採用後に他語との再配分として判断する。現在の提案では件数維持を優先してE3に置いた。

注意点: 아저씨は人物関係により呼びかけの自然さが変わる。동갑の導入価値は基本年齢語との比較が必要。
시간표は時刻の一覧という共通義に限定する。가만히は自由な結果状態構文を追加せず使えることを確認する。
충전하다と충전기は同根だが「動作」と「具体物」で別の機能がある。両方を採用する価値は再遭遇計画で確認する。
これらを無条件にhighと確定せず、初級・具体・反復可能な用例を人間が確認してから採否を決める。

## 4. 文法29→32の差分

g01〜g29は完全保持。以下の3エントリを末尾へ追加した。

| ID | form | 許可義 | 注意 |
|---|---|---|---|
| ko_k1_g30 | -(으)로 | 手段・道具・移動方向 | 母音・ㄹ後は로、それ以外の받침後は으로。資格・原因・結果・材料や로써/로서は除外 |
| ko_k1_g31 | 부터 / 까지 | 時間・場所の起点・終点 | 一対を1項目として計数。場所起点では에서부터等も許可。強調「〜さえ」は除外 |
| ko_k1_g32 | 만 | 単純な限定「〜だけ」 | 数詞万の만と区別。-기만/만에/-(으)ㄹ 만하다は追加許可しない |

助詞・文法を語彙の800件へ加算しない。
**比較 보다、와/과、-지 않다、名詞化 -기は未追加**。Coreの見る보다と既存の試行-아/어 보다は引き続き許可するが、比較用法を意味しない。
固定句5種＋通常活用괜찮아요の例外台帳は変更していない。

## 6. 98%下限・99%目標と初出token

profileの旧known_vocab_ratioを削除し、次の2キーへ置換した。

```json
{
  "hard_min_known_vocab_ratio": 0.98,
  "target_known_vocab_ratio": 0.99
}
```

98%は合否下限、99%は目標。98%以上99%未満は目標未達だが下限適合として扱う。
初出教材の新出語は最大2lemma。DBエントリも最大2にすることで、同表記の新しいsenseをまとめて導入する抜け道を防ぐ。
別senseの初出も導入負荷として計数し、500エントリの配置対象から外さない。

**初出新出語のtoken合計は原則3以下。** 2語を各3回＝6tokenにする方針ではない。
例えば2語なら出現1＋1または2＋1を基本にし、活用形も同一lemmaのtokenとして数える。
初出の中心義に該当するtokenを合算し、同表記の既出senseは別に扱う。大量反復は後続教材で行う。
既知語の近距離反復・反復推奨・言い換え不要というK1方針は維持した。

内容語・意味単位の延べtoken数をN、未知出現をUとすると既知率は(N−U)/N。

| 未知token U | hard98%に必要なN | target99%に必要なN |
|---|---:|---:|
| 1 | 50以上 | 100以上 |
| 2 | 100以上 | 200以上 |
| 3 | 150以上 | 300以上 |

3以下という上限だけで98%達成を保証しない。N＝100で未知3なら97%、N＝150で未知3なら98%。
実際のNと、既知率に影響する未習得Core・未提示の固有名詞・定型句も測る必要がある。
原則3以下よりhard98%を優先し、短い本文では新出tokenを減らすか、理解を確認した読前提示を組み合わせる。
提示しただけで既知とみなさず、読前に理解可能であることを確かめる。提示語もその回の導入語数へ含める。
Uを読む途中で勝手に既知へ変更し、反復回数を比率計算から消すことはしない。

今回のvalidatorは**これらのprofile/Schemaと配置データ**を検証する。本文を生成していないため、実際の本文の比率・token数を測定した結果ではない。
3token上限は「原則」のためsoft_maxとして記録し、例外の承認基準は人間判断待ちとした。

## 8. まだ人間判断が必要な項目

1. **7組の入替の採否。** 現行500語を保持するか、各候補を正式採用するか。採用時の辞書義・用例・6教材での再使用を確認する。
2. **仮候補のTier。** 入替だけなら全候補E3で件数を保つ。もっと早く導入する語は別のTier再配分が必要。
3. **初出tokenの例外基準。** 原則3を超える例外をどの条件で認めるか。hard98%は原則として維持し、99%未達の扱いも定める。
4. **既知語集合の運用。** 内容語の分母、読前確認、同表記のsense判定、固有名詞と固定句の学習状態を記録する方法。
5. **最終25本の再遭遇密度。** 高速多読ゾーンでも、未知に近い後半E3語が集中して速度を妨げないかを台帳で確認する。
6. **Tier変更の言語・教材上の妥当性。** E1昇格2語と対になる後送り語、E2 기억하다の使用価値を確認する。
7. **確定語彙を入替する際のID移行。** 新しい語へ旧IDを流用しない。正式入替を行う次の改訂では、現行のID＝rank制約と新ID採番の移行をレビューする。
